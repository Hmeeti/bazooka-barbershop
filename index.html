Это не сайт

Адрес hmeeti.github.io — это GitHub Pages. Он умеет показывать только статичные HTML-файлы.

Наш проект — полноценный Next.js-сервис (запись, база, API, кабинет). Его нужно запускать локально или деплоить на Vercel / аналог.

Локальный запуск 
git clone https://github.com/Hmeeti/bazooka-barbershop.git
cd bazooka-barbershop
npm install
npx prisma migrate dev
npm run db:seed
npm run dev
Потом открой http://localhost:3000
